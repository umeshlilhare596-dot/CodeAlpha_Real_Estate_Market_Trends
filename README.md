Real Estate Market Trends Dashboard

Project Overview

This project analyzes real estate property prices, monthly rental income, rental yield, and market demand versus supply using Microsoft Power BI.

Key Features

- Average Property Price by City
- Average Monthly Rent by City
- Annual Rental Yield Analysis
- Market Demand vs Supply by City
- Property Prices by Locality

Tools Used

- Microsoft Power BI
- Power Query
- DAX

Files Included

- Power BI dashboard (.pbix)
- Dataset (.csv)
- Dashboard screenshot (.png)

Note

The project uses sample data for demonstration and learning purposes.
